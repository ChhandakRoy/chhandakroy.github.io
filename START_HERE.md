# Chhandak Roy — GitHub Pages starter

This is a ready-to-upload GitHub Pages + Jekyll starter for `ChhandakRoy.github.io`.

## Publish

1. Create a **public** GitHub repository named exactly `ChhandakRoy.github.io`.
2. Upload all files from this folder, preserving folders beginning with `_` and `.github`.
3. In **Settings → Pages**, set **Source** to **GitHub Actions**.
4. Commit/push to `main`.
5. Open `https://chhandakroy.github.io`.

The included workflow builds the Jekyll site and deploys it with GitHub Pages.

## Included

- Custom responsive dark engineering-style design
- Home, About, Projects and Blog pages
